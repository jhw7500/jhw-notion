# /jhw:context — 프로젝트 컨텍스트 로드

1. 프로젝트를 식별한다:
   - 인자로 프로젝트명이 제공된 경우 → 그대로 사용
   - 인자가 없는 경우 → `jhw_status`로 프로젝트 목록을 보여주고 선택

2. `jhw_context` MCP 도구를 호출한다.

3. 결과를 구조화하여 보여준다:
   ```
   📂 프로젝트 컨텍스트: wlan-bridge
   ─────────────────────────────
   상태: 진행중 | 스택: C | 시작: 2026-04-01
   레포: ~/ai/claude/wlan-bridge

   📋 관련 결정 (2건):
     1. libpcap → raw socket 전환 (확정)
     2. TPACKET_V3 도입 (확정)

   📝 페이지 내용: ...
   ─────────────────────────────
   ```

## 사용 시점

- 새 세션에서 기존 프로젝트 작업을 재개할 때
- 프로젝트 전체 맥락을 빠르게 파악하고 싶을 때

## 규칙

- 조회 전용 — 데이터를 수정하지 않는다.
