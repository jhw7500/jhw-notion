# /jhw:history — 프로젝트 타임라인

1. 프로젝트를 식별한다:
   - 인자로 프로젝트명이 제공된 경우 → 그대로 사용
   - 인자가 없는 경우 → `jhw_status`로 프로젝트 목록을 보여주고 선택

2. `jhw_history` MCP 도구를 호출한다.

3. 시간순 타임라인으로 보여준다:
   ```
   📅 타임라인: wlan-bridge
   ─────────────────────────────
   2026-04-01  🟢 프로젝트 시작
   2026-04-01  📋 libpcap 기반으로 구현 (확정)
   2026-04-05  📋 libpcap → raw socket 전환 (확정)
   ─────────────────────────────
   총 3건
   ```

## 사용 시점

- 프로젝트 경과를 회고할 때
- 어떤 결정이 언제 내려졌는지 추적할 때

## 규칙

- 조회 전용 — 데이터를 수정하지 않는다.
- 폐기된 결정도 포함하되 ❌ 표시로 구분한다.
