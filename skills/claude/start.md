# /jhw:start — 프로젝트 시작 원스톱

1. 프로젝트 정보를 수집한다 (인자가 있으면 파싱, 없으면 인터뷰):
   - 프로젝트명 (필수)
   - 레포 경로 (선택)
   - 기술 스택 (선택)
   - 한 줄 설명 (필수)

2. 미리보기를 보여주고 승인을 받는다:
   ```
   🚀 새 프로젝트 시작
   ─────────────────────────────
   프로젝트명: wlan-bridge VLAN 지원
   레포: ~/ai/claude/wlan-bridge
   스택: C
   설명: 802.1Q VLAN 태그 처리 지원

   생성될 항목:
     ✅ Projects DB 레코드 (상태: 진행중)
     ✅ Decision Log "프로젝트 시작" 기록
     ✅ 프로젝트 페이지에 기본 템플릿
   ─────────────────────────────
   진행할까요?
   ```

3. 승인 후 `jhw_start` MCP 도구를 호출한다.

4. 결과를 보여준다.

## 규칙

- 동일 프로젝트명이 이미 존재하면 경고하고 확인을 받는다.
- 반드시 사용자 승인 후에만 생성한다.
