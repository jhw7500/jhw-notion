# /jhw:review — 세션 마무리 리뷰

1. 현재 세션의 대화 내용을 분석하여 다음을 추출한다:
   - 새로운 기술 결정 (Decision Log 후보)
   - AI 사용 피드백/선호도 (Preferences 후보)
   - 프로젝트 상태 변경 (Projects 후보)
   - 새로운 참조 문서 (References 후보)

2. 추출된 항목을 테이블로 정리하여 보여준다:
   ```
   📋 세션 리뷰 — Notion 저장 후보
   ─────────────────────────────
   #  DB            제목                    저장?
   1  Decision Log  libpcap → raw socket    ✅
   2  Preferences   한국어 응답 선호         ✅
   3  Projects      wlan-bridge 상태→완료    ✅
   ─────────────────────────────
   전체 저장? 또는 번호로 제외 (예: "2번 빼")
   ```

3. 사용자가 승인/수정한다:
   - "OK" / "전체 저장" → 전부 저장
   - "2번 빼" → 2번 제외하고 저장
   - "취소" → 저장 안 함

4. 승인된 항목마다 `jhw_record` MCP 도구를 호출한다.

5. 저장 결과 요약을 보여준다.

## 사용 시점

- 세션 종료 전
- 긴 작업 구간이 끝났을 때
- 사용자가 "기록할 거 있어?" 라고 물었을 때

## 규칙

- 저장 후보가 없으면 "이번 세션에서 저장할 항목이 없습니다"로 응답한다.
- 실패한 시도나 중간 과정은 후보에서 제외한다.
- 이미 저장된 항목은 중복 제안하지 않는다.
