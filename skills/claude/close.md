# /jhw:close — 프로젝트 종료 원스톱

1. 종료할 프로젝트를 식별한다:
   - 인자로 프로젝트명이 제공된 경우 → 그대로 사용
   - 인자가 없는 경우 → `jhw_status`로 "진행중" 프로젝트 목록에서 선택

2. 회고를 작성한다 (사용자 인터뷰):
   - "이 프로젝트에서 뭘 달성했나요?"
   - "배운 점이나 다음에 다르게 할 것이 있나요?"

3. 미리보기를 보여주고 승인을 받는다:
   ```
   📝 프로젝트 종료 처리
   ─────────────────────────────
   처리 항목:
     ✅ Projects DB 상태 → 완료, 완료일 설정
     ✅ 프로젝트 페이지에 회고 섹션 추가
     ✅ Knowledge Base에 학습 사항 등록 (있는 경우)
   ─────────────────────────────
   진행할까요?
   ```

4. 승인 후 `jhw_close` MCP 도구를 호출한다.

5. 결과를 보여준다.

## 규칙

- 이미 "완료" 상태인 프로젝트는 "이미 종료된 프로젝트입니다" 안내.
- 회고 작성은 선택사항 — 사용자가 "건너뛰기"하면 상태만 변경.
- 반드시 사용자 승인 후에만 처리한다.
